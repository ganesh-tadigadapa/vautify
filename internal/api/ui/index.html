08 · 09 — Integrity & Partitions

Bad bytes and broken links

Two failures that look alike from outside and get different treatment inside. A node whose bytes are wrong still answers. A node behind a partition has correct bytes but can't be reached.

10 — Quorum & Consistency

Metadata names the truth. Quorum proves it.

A write is acknowledged once W replicas have stored and verified it. A read returns bytes only when R replicas hold the current version with the metadata checksum.
